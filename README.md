## 🔬 Featured Projects & Research

### 1. [RetinaXplain](https://github.com/abdullahse2211/diabetic-retinopathy-classification)
*A Hybrid CNN-Vision Transformer Framework for Diabetic Retinopathy Severity Classification*
- **Architecture:** Swin Transformer Tiny, ViT-B/16, EfficientNet-B3 with weighted soft voting ensemble.
- **Preprocessing:** Ben Graham color normalization, circular cropping, and illumination correction on 3,662 APTOS 2019 fundus images (augmented to ~16,000).
- **Results:** Achieved **85.27% validation accuracy** and **0.7216 macro-F1** on 5-class severity classification.
- **Deployment:** Multi-page Streamlit application with live inference latency tracking.

### 2. BioNAFNet
*Knowledge-Distilled Non-Linear Activation-Free Network for Low-Light Endoscopic Image Restoration*
- **Architecture:** Compressed NAFNet baseline from 67.9M params down to **10.6M params (6.4× reduction)** using multiscale perceptual loss and feature distillation.
- **Performance:** Maintained **32.8 dB PSNR** and **0.912 SSIM** at **60+ FPS** on embedded GPU targets.

### 3. [ThalCare](https://github.com/abdullahse2211/ThalCare)
*Multi-Class ML Diagnostic System for Alpha Thalassemia Carrier Detection*
- **Algorithms:** Evaluated 6 ML architectures (hybrid CNN-Transformer, 1D-CNN, SVM, RF, LR) with 15 engineered features on CBC/HPLC parameters.
- **Performance:** **90.60% balanced accuracy** and **0.906 weighted F1** under injected clinical noise, elevating Silent Carrier F1 to **0.92–0.955**.
- **Demonstration:** [Watch YouTube Demo](https://youtu.be/ciiGgdlZ4d4?si=_xKxSkJOZ9t3njEA)

### 4. RogueAP-Scanner
*802.11 Wireless Intrusion Detection & Evil Twin Attack Prevention Engine*
- **Capabilities:** Real-time raw packet sniffing with Scapy, fingerprinting rogue access points, BSSID/ESSID spoofing alerts, and automated defensive countermeasures.
